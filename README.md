# Odyssey IMAX Watcher — הוראות התקנה

בודק כל 15 דקות הקרנות IMAX של "האודיסאה" בפלאנט ראשל"צ בין 18:00–23:00, ושולח טלגרם כשמופיעה הקרנה חדשה (או שמתפנים מקומות בהקרנה שהייתה מלאה) עם לפחות 4 מושבים פנויים.

## שלב 1 — בוט טלגרם (2 דקות)
1. בטלגרם, פתח שיחה עם **@BotFather** → שלח `/newbot` → תן שם → קבל **טוקן** (שמור אותו).
2. שלח הודעה כלשהי לבוט החדש שלך (חובה, אחרת הוא לא יכול לכתוב לך).
3. גלוש ל: `https://api.telegram.org/bot<הטוקן>/getUpdates` — תראה JSON עם `"chat":{"id":123456789}` — זה ה-**chat id** שלך.

## שלב 2 — GitHub
1. צור ריפו **פרטי** חדש, העלה אליו את שלושת הקבצים (שמור על המבנה: `watcher.py`, `README.md`, `.github/workflows/watch.yml`).
2. Settings → Secrets and variables → Actions → New repository secret:
   - `TELEGRAM_BOT_TOKEN` = הטוקן מ-BotFather
   - `TELEGRAM_CHAT_ID` = ה-id מהשלב הקודם
3. טאב **Actions** → Odyssey IMAX Watcher → **Run workflow** להרצת בדיקה ידנית.

בהרצה הראשונה כל ההקרנות הקיימות ייחשבו "חדשות" — כך תקבל מיד הודעה עם כל מה שזמין כרגע, ומשם רק על שינויים.

## התאמות
בראש `watcher.py`:
- `HOUR_MIN / HOUR_MAX` — טווח השעות
- `MIN_SEATS` — מינימום מושבים
- `DAYS_AHEAD` — כמה ימים קדימה לסרוק

## מגבלה ידועה
הבדיקה היא על **סה"כ מושבים פנויים** (משדה availabilityRatio של ה-API), לא על 4 צמודים — מפת המושבים דורשת session של תהליך רכישה. עם סף של 4+ פנויים באולם IMAX גדול, כמעט תמיד יהיו גם צמודים.
